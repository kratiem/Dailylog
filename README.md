# Daily Log (GitHub Pages shell)

バナー非表示用の薄いラッパーです。本体は Google Apps Script 上で動きます。

## 公開 URL

https://kratiem.github.io/Dailylog/

## 使い方

1. このリポジトリで GitHub Pages を有効化（Settings → Pages → Deploy from branch `main` / `/ (root)`）
2. 上記 URL をブックマークして利用する
3. `script.google.com` の直リンクは使わない（バナーが出る）

## 更新

GAS のデプロイ ID が変わったら `index.html` 内の `GAS_EXEC` を更新して push する。
